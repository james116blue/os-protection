## О курсе

Курс посвящён практическим основам защиты операционных систем: безопасность
загрузки, разграничение доступа, аудит и мониторинг, защита данных и сети.
Каждое занятие состоит из **теории** (материалы лекции) и **лабораторной работы**.

## Структура репозитория

Каждое занятие — отдельный каталог с единой структурой:

```
занятие N <тема> ДД.ММ.ГГГГ/
├── README.md        # описание занятия: тема, план, ссылки
├── лекция/          # теория: конспект и презентация лекции
└── лабораторная/    # задание и материалы к лабораторной работе
```

## Как сдавать работы

Отчёты принимаются в форматах **Word (.docx), PDF или Markdown** — со скриншотами
внутри. Оценка выставляется по критериям преподавателя: **зачёт / незачёт**.

### Что нужно для зачёта по лабораторным

- **Лабораторная 1 — безопасность загрузки (GRUB2):** достаточно **работы 1** — защиты
  загрузчика GRUB2 паролем (`grub-mkpasswd-pbkdf2` → `password_pbkdf2` в
  `/etc/grub.d/40_custom`, затем `update-grub`). Работа 4 (UEFI Secure Boot и подписи
  модулей ядра) — **по желанию**.
- **Лабораторная 2 — эскалация привилегий:** достаточно **заданий 1, 3 и 4**.
  Задания 2, 5 и 6 — **по желанию**.

Точные требования к отчёту и скриншотам — в тексте задания соответствующей лабораторной.
