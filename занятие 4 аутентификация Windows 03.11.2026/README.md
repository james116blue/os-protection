# Занятие 4 — Аутентификация Windows (NTLM)

**Дата:** 03.11.2026

## Лабораторная

- [Задание](лабораторная/лабораторная_4.md)
- [Задание (PDF)](лабораторная/лабораторная_4.pdf)

**Тема:** аутентификация в Windows, протокол NTLM и атаки на него:
извлечение NTLM-хешей из хранилища SAM и из дампа процесса `lsass.exe`,
восстановление паролей по хешу (hashcat), настройки безопасности,
запрещающие LM- и NTLM-аутентификацию.

**Стенд:** виртуальная машина Windows 10 (стенд NTLM). Пользователи стенда:
`administrator` (рабочая учётная запись с правами администратора), `Vera`, `Kate`,
`John`. Задача — извлечь хеши и восстановить пароли `Vera` и `Kate`.

**Инструменты:** Mimikatz, Hashcat (архив `hashcat-6.1.1.7z` прилагается
к заданию), оснастка «Локальная политика безопасности».
